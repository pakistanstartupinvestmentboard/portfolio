# Huzaif ur Rehman — portfolio

Static site deployed on Vercel.

- Edit content in `assets/data.js` (roles, dates, tools) and page text in `src/index.html`.
- Then run `python3 tools/build.py` to regenerate `index.html`.
- `assets/photo.webp` is the profile photo; add `assets/cover.webp` to use an image cover.
- Keep `llms.txt` in step with experience changes.
